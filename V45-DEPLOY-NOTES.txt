IMPORTANT SECURITY NOTE
The requested login method uses only a registered email and deliberately does not use OTP/email verification. It can confirm that an email is registered and syntactically valid, but it cannot prove that the person typing that email owns the mailbox. If stronger identity protection is required later, add a password or restore email verification.

STATIC PDF NOTE
Website UI access is gated before PDFs can be opened. Because PDFs are static files inside a deployable website package, a person who already knows a direct PDF asset URL may be able to request that URL directly from a static host. Fully server-enforced PDF protection requires serving PDFs from private storage or an authenticated server endpoint.
