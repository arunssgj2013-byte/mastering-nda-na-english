# TAT Mock Test 3 — Original Black-and-White Illustrations

Eleven new illustrative scenes authored for Mastering NDA English SSB-style practice, created from scratch using custom drawing code without copying or tracing third-party TAT images.

These educational illustrations are not official SSB selection-board test pictures and do not depict real candidates or events.

Practice sequence: picture-01.webp through picture-11.webp, then the timed twelfth blank slide.

Timing per picture: 30 seconds observation + 4 minutes writing (54 minutes total). Images are optimised 900 × 675 WebP.

Scenes: village footbridge; railway platform; clinic; classroom; agricultural field; mountain trail; repair workshop; road crossing; riverside boat; study hall; residential courtyard.

No model answers are embedded in the images.
