## Online mock-test format

- Pictures 1–11: displayed in order for **30 seconds**, then a **4-minute** story-writing period each.
- Stimulus 12: a **blank slide**, generated directly by `tat-practice.html`, with the same 30-second observation and four-minute story-writing intervals.
- Total test time: **54 minutes**.
- Handwritten mode is recommended. Candidates do not need to upload their story sheets.
- Existing website registration/login applies; start and finish activities are recorded in the student/Admin Hub without uploading private stories.

## Website integration

`tat-practice.html` preloads the eleven images at `assets/tat/mock-1/` and enables Mock Test 1 when every image is available. No local PDF upload is needed. The other mock tests remain pending their respective picture banks.

All pictures were provided for this educational practice by the website owner. Publish or redistribute only with the necessary permissions for any third-party source images.
