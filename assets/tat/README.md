# TAT picture bank for SSB Corner

This folder is reserved for the **75-picture optimised PDF**, created from the website owner's supplied 125-page source. The practice page is `tat-practice.html`.

## Publish the picture bank

1. Open https://masteringndaenglish.com/tat-practice.html on a **desktop**.
2. Expand **Website editor / local preview**, then select the original **125-page** PDF.
3. Expand **Website editor: create an optimised 75-picture PDF**, and click **Make Optimised 75-Picture PDF**.
4. Once complete, you will have `tat-pictures-75-optimised.pdf`.
5. Open [Upload to this folder](https://github.com/arunssgj2013-byte/mastering-nda-na-english/upload/main/assets/tat) and upload the PDF with that exact filename.
6. Wait for GitHub Pages deployment, then reload the TAT page. It should recognise the **75 pages** and enable the test.

Only publish pictures that you have permission to reproduce. Prefer the optimised file for mobile users, **not** the ~98 MB original collection.

The six mock sets use 66 selected pictures and nine additional pictures support single-image practice. Each full mock has 11 pictures and a twelfth blank-slide story (30 seconds + 4 minutes per story).
