# TAT Mock Test 4 images

Upload `picture-01.webp` through `picture-11.webp` to this directory. The timed practice page (`tat-practice.html?mock=4`) automatically enables Mock Test 4 only when all 11 files load successfully. The twelfth slide is the built-in blank slide; no picture upload is required for it.

The pictures were originally generated as black-and-white educational illustrations to avoid reproducing externally sourced SSB coaching images directly.
