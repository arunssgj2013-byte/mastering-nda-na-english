# TAT Mock Test 5 images

Upload `picture-01.webp` through `picture-11.webp` to this directory. The timed practice page (`tat-practice.html?mock=5`) enables Mock Test 5 after all 11 original pictures load successfully. The twelfth slide is the built-in blank slide; no picture upload is required for it.

These are newly generated, original black-and-white TAT practice scenes. The test uses the same 30-second observation and 4-minute writing periods as the existing full mocks.
